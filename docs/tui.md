# TUI ガイド

## 概要

mcpax の TUI（Terminal UI）は Textual を使ったインタラクティブな操作画面です。CLI と同じ設定ファイルを使い、検索・追加・削除・更新・設定変更を画面上で行えます。

## 事前準備

TUI は optional dependency です。開発版を使う場合は追加で Textual をインストールしてください。

```bash
uv pip install -e ".[tui]"
```

`config.toml` と `projects.toml` が必要です。まだ作成していない場合は先に `mcpax init` を実行してください。

## 起動

```bash
mcpax tui
```

起動時に設定が見つからない場合はエラーメッセージで終了します。

## 主な画面

| 画面 | 説明 |
|------|------|
| Main | プロジェクト一覧 + 検索入力 + ステータス |
| Search | Modrinth 検索結果（追加操作） |
| VersionSelect | バージョン選択（ピン留め or 最新） |
| Detail | プロジェクト詳細（削除操作） |
| Install | インストール/更新の進捗とサマリー |
| Settings | `config.toml` の編集 |

## キーバインド

### Main 画面

| キー | 操作 |
|------|------|
| `q` | 終了 |
| `r` | 更新チェック（再取得） |
| `i` | 全プロジェクトのインストール/更新 |
| `s` | 設定画面を開く |
| `d` | 選択中プロジェクトを削除（確認ダイアログあり） |
| `D` | NOT_COMPATIBLE なプロジェクトを一括削除（確認ダイアログあり） |
| `Enter` | 選択中プロジェクトの詳細を表示 |

### Search 画面への移動

Main 画面上の **SearchInput ウィジェット**にクエリを入力して `Enter` を押すと Search 画面が開きます。専用キーはありません。

### Search 画面

| キー | 操作 |
|------|------|
| `a` | 選択中プロジェクトを追加（バージョン選択画面へ） |
| `Esc` | Main 画面へ戻る |

### VersionSelect 画面

| キー | 操作 |
|------|------|
| `Enter` | 選択中バージョンをピン留めして追加 |
| `l` | 最新バージョン（ピン留めなし）で追加 |
| `Esc` | Search 画面へ戻る |

### Detail 画面

| キー | 操作 |
|------|------|
| `d` | 削除（確認ダイアログあり） |
| `Esc` | 閉じる |

### Install 画面

| キー | 操作 |
|------|------|
| `Esc` | キャンセル / 完了後に閉じる |

### Settings 画面

| キー | 操作 |
|------|------|
| `Enter` | 選択中の設定項目を編集 |
| `Esc` | Main 画面へ戻る |

## 補足

- TUI は CLI と同じコアロジックを使用します。
- 追加したプロジェクトは `projects.toml` に保存されます。
- `d` / `D` の削除操作は確認ダイアログを表示し、承認後に `projects.toml` から対象プロジェクトを削除します。
- `D` は現在の更新チェック結果で `NOT_COMPATIBLE` のプロジェクトのみを対象にします。
